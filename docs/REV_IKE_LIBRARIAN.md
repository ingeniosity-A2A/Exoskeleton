# Rev.Ike — Librarian Task Functions

**Subsystem owner:** Exoskeleton  
**Scope:** task-function reference only  
**Canonical subsystem definition:** `docs/REV_IKE.md`

## Functions

1. **Ingest** — accept data/artifacts through an explicit source contract.
2. **Normalize** — validate and map inputs into versioned chassis-ready records.
3. **Curate** — create, merge, retire or stop workspace/artifact operations where the backing store supports the operation safely.
4. **Preserve provenance** — retain source, version, transformation and lineage references.
5. **Authorize serving** — enforce identity grants before read, materialize or serve.
6. **Report outcomes** — return structured status, errors and trace references to Exoskeleton.

## Non-functions

- Governing Ava007 intelligence or reasoning.
- Replacing Cybernetic-Ava007 as the authority for intent and purpose.
- Owning the Omni-OS device/operating environment.
- Owning A2A protocol documentation (MA Computing owns that material).
- Assuming that every intake path is zero-copy or every curation operation is transactional without implementation evidence.

Rev.Ike is not a separate framework authority. These functions execute within the Exoskeleton boundary.
